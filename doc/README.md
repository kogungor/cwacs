# cwacs documentation

This folder is the in-repo documentation source for `cwacs.nvim`.

## Update policy

- This folder must be updated at the end of every feature milestone.
- At minimum, update:
  - `doc/feature-log.md` (what changed in that feature)
  - `doc/cwacs.md` (user-facing behavior/config/commands)
- If Neovim help behavior changed, also update `doc/cwacs.txt`.

## Files

- `doc/cwacs.md`: full project documentation
- `doc/feature-log.md`: per-feature changelog and status
- `doc/cwacs.txt`: Vim help format (for `:help cwacs` later)
